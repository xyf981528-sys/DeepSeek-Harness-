# 文件传输台 · 使用说明书

适用版本：`dsh-file-station` 0.7.x（DSH Desktop 插件）
最后更新：2026-10-26

---

## 1. 这是什么

文件传输台让手机和电脑在**同一局域网**或 **Tailscale 私有网络**里直接互传文件、图片和文字，不需要数据线、不需要登录云盘。

它由三部分组成：

| 部分 | 作用 |
|---|---|
| DSH 插件 Host | 在电脑上开手机服务（默认 19790）、管理文件与访问码 |
| 手机网页 | 聊天式界面：发消息、图片、文件，浏览共享目录 |
| Android APK | 把同一个手机网页装成 App，带内置下载器 |

---

## 2. 环境要求

- Windows 10/11，已安装并运行 DSH Desktop
- 手机与电脑在同一 WiFi，或两端都装了 Tailscale
- 默认端口 **19790/TCP** 未被其他程序占用
- Android APK 需要 Android 8.0+；Android 10+ 保存到系统「下载/文件传输台」

---

## 3. 安装插件

### 方式 A：从 GitHub 安装（推荐）

```powershell
dsh plugin --profile desktop add "git+https://github.com/xyf981528-sys/DeepSeek-Harness-.git#path:/dsh-file-station"
```

### 方式 B：本地安装

```powershell
dsh plugin --profile desktop add "D:\DeepSeek Y\dsh-file-station"
```

### 方式 C：插件管理器

插件管理器 → 安装本地包 → 选择 `dsh-file-station` 目录。

安装后**重启 DSH**。确认服务正常：

```powershell
curl.exe -s -o NUL -w "%{http_code}`n" "$env:DSH_WEB_URL/file-station/api/status"
```

返回 `200` 即正常。

## 4. 第一次连接手机

1. 打开 DSH 侧边栏「工具箱」→「文件传输」→「展开详情」。
2. 点「👁 显示连接地址」。
3. 用手机扫二维码，或复制地址在浏览器打开：

```
http://<电脑局域网IP>:19790/?k=<访问码>
```

4. 首次访问会生成新设备记录；在电脑打开：

```
http://127.0.0.1:19790/pair-admin
```

点「允许」。之后同一设备不用再批准。

> 地址和二维码默认隐藏，显示后 90 秒自动收起；收起后二维码里的访问码失效。

## 5. 手机界面怎么用

### 聊天

- 底部输入框输入文字，点「发送」或按回车。
- 电脑的回复会出现在左侧深色气泡；自己的消息在右侧蓝色气泡。
- 点文字气泡可复制这条消息。

### ＋ 工具面板

点输入框左侧「＋」：

| 工具 | 作用 |
|---|---|
| 图片 | 选择照片，先进入附件条，可预览/删除 |
| 文件 | 选择任意文件，进入附件条 |
| 截屏 | 让电脑截屏，手机弹窗查看 |
| 共享文件 | 打开电脑共享目录/上传目录/额外目录 |
| 清空对话 | 清空手机与电脑之间的消息 |
| 压缩图片 | 发送前把长边压到 1600、JPEG 0.9 |
| 存成 txt | 文字同时存成 `文本-*.txt` |
| 电脑提醒 | 电脑弹窗/响铃提醒 |

点空白遮罩、Android 返回键或 Esc 关闭面板。

### 附件条

选好的图片/文件先放在输入框上方：

- 显示缩略图或文件名
- `✕` 移除
- 点「发送」才真正上传
- 上传时显示进度，可「取消」

### 共享文件抽屉

「共享文件」打开半屏抽屉：

- **文件**：共享文件夹、上传文件夹、额外共享目录；点文件夹进入，点文件下载。
- **文字**：共享目录里的 `.txt/.md/.log` 等，点开可复制全文。

## 6. 文件都放在哪

| 内容 | 位置 |
|---|---|
| 手机上传的文件 | `data\上传\` |
| 聊天图片 | `data\上传\对话图片\` |
| 共享文件 | `data\共享\` |
| 收件箱/留言 | `data\收件箱.jsonl`、`data\留言.jsonl` |
| 访问码 | `data\_token.txt` |
| 额外共享目录 | 面板里添加，如 `E:\照片` |
| HTTPS 证书 | `certs\`（不要上传/分享） |

## 7. 上传与下载

### 上传

- 图片默认压缩后上传；可在工具面板关闭「压缩图片」。
- 普通文件 ≤6MB 直接上传；>6MB 自动分片、支持断点续传。
- 上传中可以取消；已选附件会保留，方便重试。
- 文件太大或磁盘不足会提示具体原因。

### 下载

- 手机网页和 APK 都使用**短时签名下载地址**，不需要在下载器里带 Cookie。
- 签名有效期 2 分钟，点击后立即开始。
- APK 1.3+ 使用内置下载器：
  - 显示进度，可取消
  - Android 10+ 保存到「下载/文件传输台」
  - Android 9 及以下保存到公共下载目录（需存储权限）
- 网页端由浏览器下载，保存位置由浏览器决定。

## 8. 不在同一 WiFi：Tailscale

1. 电脑和手机都安装 Tailscale，登录同一账号。
2. 电脑查自己的 Tailscale IP：

```powershell
"C:\Program Files\Tailscale\tailscale.exe" ip -4
```

3. 手机把访问地址里的局域网 IP 换成 Tailscale IP，端口仍是 `19790`：

```
http://<Tailscale-IP>:19790/?k=<访问码>
```

4. 首次使用这个地址，需要在 `http://127.0.0.1:19790/pair-admin` 批准新设备。
5. 如果打不开，检查 Windows 防火墙是否允许 TCP 19790（Private/Domain）。

Tailscale 是私有网络，不需要公网端口转发；不要把 19790 直接暴露到公网。

## 9. Android APK

### 安装

- 从共享目录下载 `文件传输台.apk` / `filestation.apk`，覆盖安装。
- 或自行构建：

```powershell
D:\DeepSeek Y\dsh-file-station\android\build.ps1
```

产物：`android\dist\filestation.apk`。

当前构建：**1.5（versionCode 6）**。APK 自带聊天优先页面与内置下载器。

### 使用

- 首次打开填地址：菜单「设置地址」→ 输入 `http://<IP>:19790/?k=...`。
- 页面加载的是电脑上的手机页，电脑端改 UI 后刷新即可。
- 下载走内置下载器，保存到「下载/文件传输台」。
- 菜单「用 HTTP 打开」：把 19791 的 HTTPS 地址换成 19790；如果已经是 HTTP，只重载。

## 10. HTTPS（可选）

默认用 HTTP 19790，简单稳定。需要 HTTPS 时：

1. 在电脑生成自签 CA/证书（`certs\`）。
2. 手机安装 CA 证书。
3. 访问 `https://<电脑IP>:19791/?k=...`。

注意：

- 自签证书可能被 Android 下载器拒绝；下载仍优先用 HTTP 19790。
- 不要把 `certs\` 里的私钥上传或发给别人。

---

## 11. 安全建议

- 访问码等同于密码，不要发到公开群/截图里。
- 新设备必须配对批准；不用时在 `/pair-admin` 撤销。
- 只在家/公司局域网或 Tailscale 内使用，不要把 19790 映射到公网。
- `data\` 里有聊天记录、上传文件、访问码；`certs\` 有私钥，均不要上传 GitHub。
- 公共电脑使用完可「重置访问码」，让旧链接失效。

## 12. 常见问题

| 现象 | 处理 |
|---|---|
| 手机打开显示 `unauthorized` | 地址里的 `?k=` 访问码不对/已重置；重新从面板显示地址 |
| 显示 `device pending approval` | 电脑打开 `http://127.0.0.1:19790/pair-admin` 点允许 |
| 下载失败 / 无权访问 | 用 HTTP 19790；APK 升级到 1.4+；确认签名 URL 未过期 |
| 网页能下、APK 不能下 | 旧 APK 的 DownloadManager 问题；装 1.4+ 内置下载器 |
| 端口 19790 被占用 | 关闭占用程序，或修改插件端口配置后重启 |
| 手机连不上 | 确认同一 WiFi / Tailscale 开启；防火墙放行 19790 |
| 二维码不显示 | 面板点「显示连接地址」，90 秒内扫码 |
| HTTPS 证书警告 | 安装 `certs\ca.crt.pem` 到手机信任；或改用 HTTP |
| APK 装不上 | 允许「安装未知来源」；覆盖安装需同签名 |

## 13. 升级、备份与卸载

- 升级：替换 `dsh-file-station` 源码/包 → 重启 DSH → 手机刷新。
- 备份：复制整个 `dsh-file-station`，至少保留 `data\` 和 `certs\`。
- 卸载：先在 DSH 插件管理器移除，再处理目录；**工具箱文件标签依赖本插件 Host，卸载前先确认不需要它**。
- 不要直接删除 profile 里指向源码的 junction。
